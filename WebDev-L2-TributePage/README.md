# Project Overview

This project was developed as part of the **Oasis Infobyte Web Development and Designing Internship (Level 2 - Task 2)**.

Unlike a traditional tribute webpage, this project focuses on creating a modern user experience while presenting the life, achievements, legacy, and contributions of Dr. Abdul Qadeer Khan.

The website combines responsive design, interactive animations, elegant typography, smooth scrolling, dynamic effects, and accessibility improvements to create a professional front-end project.
